Equazioni di secondo grado

Mappa concettuale per la verifica

Forma normale

a x² + b x + c = 0   con a ≠ 0

a = coefficiente di x² · b = coefficiente di x · c = termine noto

Equazione INCOMPLETA

Almeno uno dei coefficienti b oppure c è uguale a 0.

Equazione COMPLETA

Tutti i coefficienti sono diversi da 0:
a ≠ 0, b ≠ 0, c ≠ 0

Equazioni incomplete
PURA

a x² + c = 0  (b = 0)

  1. isolo x²:  x² = −ca
  2. se −ca > 0 → x = ±√−ca
  3. se −ca < 0 → impossibile
SPURIA

a x² + b x = 0  (c = 0)

  1. raccolgo x: x (a x + b) = 0
  2. legge di annullamento del prodotto:
    x = 0  ∨  x = −ba
MONOMIA

a x² = 0  (b = 0, c = 0)

Ha sempre la soluzione doppia:
x₁ = x₂ = 0

Equazione completa
Discriminante
Δ = b² − 4ac

Il segno di Δ dice quante soluzioni reali ha l'equazione.

Formula risolutiva
x1,2 = −b ± √Δ2a

Prima scrivo i valori di a, b, c con il loro segno.

Tocca il segno di Δ per vedere che cosa succede:

Δ > 0

Due soluzioni reali distinte

x₁ = −b − √Δ2a
x₂ = −b + √Δ2a
Δ = 0

Due soluzioni reali coincidenti

x₁ = x₂ = −b2a
Δ < 0

Nessuna soluzione reale

√Δ non esiste in ℝ: l'equazione è impossibile.
Equazione fratta

L'incognita x compare al denominatore di almeno una frazione. Dopo i passaggi si arriva a un'equazione di secondo grado a x² + b x + c = 0.

Schema risolutivo passo per passo

Mentre risolvi un esercizio, spunta i passi che hai fatto.

  1. 1
    Condizioni di esistenza (C.E.)
    Pongo ogni denominatore ≠ 0 e trovo i valori di x da escludere.
  2. 2
    Scompongo i denominatori e calcolo il m.c.m.
    Uso raccoglimenti e prodotti notevoli (vedi tabella sotto).
  3. 3
    Elimino i denominatori
    Riduco allo stesso denominatore (il m.c.m.) e uguaglio i numeratori.
  4. 4
    Riduco a forma normale
    Svolgo i calcoli, porto tutto al primo membro: a x² + b x + c = 0.
  5. 5
    Risolvo l'equazione di secondo grado
    Riconosco il tipo (monomia, pura, spuria, completa) e uso il metodo della scheda 1.
  6. 6
    Controllo le soluzioni con le C.E.
    Se una soluzione è uguale a un valore escluso → NON accettabile, la scarto.
  7. 7
    Scrivo l'insieme soluzione
    S = { … } con le sole soluzioni accettabili. Se le scarto tutte → equazione impossibile: S = ∅.

⚠ Attenzione  Anche se Δ ≥ 0, alla fine l'equazione fratta può avere meno soluzioni o essere impossibile: dipende dal confronto con le C.E. (passo 6).
