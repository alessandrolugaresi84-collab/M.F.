2 · Il metodo della parabola

Si fa sempre in 5 passi, sempre nello stesso ordine.

  1. 1Forma normale. Porto tutto a sinistra: ax² + bx + c ▢ 0 (con 0 a destra).
  2. 2Se a < 0: moltiplico per −1, cambio tutti i segni e cambio il verso. Così la parabola è sempre ∪.
  3. 3Equazione associata. Risolvo ax² + bx + c = 0: calcolo Δ e le radici.
  4. 4Disegno una parabola ∪ che passa per le radici. Non serve altro.
  5. 5Leggo la soluzione. > 0 → dove è sopra; < 0 → dove è sotto. Con ≥ e ≤ le radici sono incluse.
Il verso serve solo alla fine! Per trovare le radici uso sempre l'equazione (= 0). Il simbolo > < ≥ ≤ serve solo al passo 5.

Il trinomio è un quadrato, per esempio x² − 6x + 9 = (x − 3)². Un quadrato non è mai negativo: vale 0 solo nella radice.

Δ < 0

La parabola sta sempre sopra l'asse: il trinomio è sempre positivo.
Scorciatoia: x² + 9 > 0 è sempre vera, x² + 9 < 0 è impossibile.

4 · Fratte e prodotti: la tabella dei segni

È la stessa delle disequazioni di primo grado. La novità: una riga può essere di secondo grado. Il suo segno lo leggo con la parabola.

  1. 1Forma normale ND ▢ 0. Non moltiplico per il denominatore!
  2. 2C.E.: D ≠ 0 (il denominatore non può essere zero).
  3. 3Studio N > 0 e D > 0. Primo grado: come sempre. Secondo grado: con la parabola.
  4. 4Tabella dei segni: una riga per N, una per D, poi il segno del risultato.
  5. 5Scelgo le colonne con il segno giusto. Gli zeri del denominatore sono sempre esclusi (∄).
Mai moltiplicare per il denominatore! Non so se è positivo o negativo, quindi non so se il verso cambia.
Regola dei segni: + per + = +  ·  − per − = +  ·  + per − = −
Esempi svolti: la tabella si costruisce una riga alla volta
IN PAROLE SEMPLICIStudio ogni pezzo da solo, metto i segni nella tabella e li moltiplico. I numeri che azzerano il denominatore non vanno mai.

5 · Sistemi: parabola + biscioline

Un sistema si riconosce dalla parentesi graffa {. Le disequazioni devono essere vere tutte insieme.

  1. 1Risolvo ogni disequazione con il suo metodo: primo grado, parabola o tabella dei segni.
  2. 2Disegno una per ogni disequazione, una sotto l'altra.
  3. 3Soluzione = dove ci sono tutte le biscioline insieme.
Attenzione: se una disequazione è impossibile, tutto il sistema è impossibile.
Se una è sempre vera (∀x ∈ ℝ), non toglie nessun valore.
Esempi svolti
IN PAROLE SEMPLICIRisolvo una disequazione alla volta. Poi cerco la zona dove tutte le soluzioni sono vere insieme.
